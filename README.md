# 🛒 E-Commerce-Conversion-Rate

Swiggy E-Commerce Conversion Rate Analysis using Microsoft Excel


## 1. Project Overview

The **E-Commerce Conversion Rate Analysis Dashboard** is an interactive business intelligence solution built using **Microsoft Excel** to analyze customer behavior and conversion performance using a Swiggy-inspired e-commerce dataset. The dashboard transforms raw transactional data into meaningful visual insights, enabling users to evaluate customer visits, completed orders, conversion rates, revenue trends, and sales performance through an intuitive and interactive dashboard.

Designed with a clean and professional layout, the dashboard helps identify factors influencing customer conversions and demonstrates how Excel can be used to perform business analytics and support data-driven decision-making.



## 2. Project Objective

The primary objective of this project is to analyze customer conversion behavior and present actionable insights through interactive visualizations. The dashboard enables users to:

- Analyze the overall e-commerce conversion rate.
- Compare customer visits with completed orders.
- Monitor sales and revenue performance.
- Identify trends in customer purchasing behavior.
- Track important KPIs using interactive dashboard elements.
- Support business decisions through data-driven insights.



## 3. Tech Stack

The dashboard was developed using the following tools and technologies:

- 📊 **Microsoft Excel** – Dashboard development and data visualization.
- 📋 **Pivot Tables** – Data summarization and analysis.
- 📈 **Pivot Charts** – Interactive charts and visual reporting.
- 🎛️ **Slicers** – Dynamic filtering and dashboard interactivity.
- 📄 **CSV/Excel Dataset** – Swiggy E-Commerce dataset used for analysis.



## 4. Data Source

**Dataset:** Swiggy E-Commerce Conversion Dataset (CSV/Excel)

The dataset contains customer transaction and order-related information, including:

- Customer ID
- Order ID
- Order Date
- City
- Restaurant
- Food Category
- Order Status
- Order Value
- Payment Method
- Customer Visits
- Completed Orders
- Conversion Status
- Revenue

The raw dataset was cleaned, organized, and prepared in **Microsoft Excel** before building the dashboard.



## 5. Business Problem

E-commerce businesses receive thousands of customer visits every day, but only a portion of those visitors complete a purchase. Understanding customer behavior and identifying the factors that influence conversion rates are essential for improving sales performance and increasing revenue.

This dashboard addresses that challenge by transforming raw sales and customer data into interactive visualizations that help businesses monitor conversion performance, evaluate customer behavior, and identify opportunities to improve the purchasing experience.



## 6. Dashboard Features

## 7. Key Insights

The dashboard provides several valuable insights into customer conversion behavior:

- Higher customer visits generally lead to increased completed orders when supported by effective customer engagement.
- Certain food categories generate higher conversion rates and revenue than others.
- Revenue growth is closely associated with improvements in customer conversion performance.
- Completed orders contribute significantly more to overall business revenue than cancelled or abandoned orders.
- Interactive slicers allow users to analyze sales performance based on city, category, order status, and time period for deeper business analysis.
